# Product and Capability Contract

The machine-readable authority is [`../governance/product-contract.json`](../governance/product-contract.json). This document explains that contract for operators; it does not create a second authority.

## Product

World-Class SEO Agent System is a model-agnostic, evidence-governed SEO operating system. Its primary layer is documentation-first knowledge, skills, evidence, and orchestration contracts. Its executable layer is a bounded CLI runtime and optional integration adapters.

The primary operator is a technical SEO practitioner or SEO engineer accountable for an authorized audit and implementation handoff. Supported secondary users are SEO strategists and analysts, agency and in-house SEO teams, growth and product engineers, and coding-agent users.

## Sole flagship

`seoctl audit technical` is the sole flagship command. It performs bounded read-only diagnosis and produces a decision-ready technical SEO evidence package:

1. `crawl.json`
2. `findings.json`
3. `decisions.json`
4. `agent-contributions.json`
5. `trust-summary.json`
6. `technical-audit.md`
7. `executive-summary.md`
8. `remediation-plan.csv`
9. `verification-plan.json`
10. `run-manifest.json`

Fixture execution proves deterministic contract behavior only. A bounded live run reports observations from an authorized target at a stated time. Neither mode proves complete site coverage, search-engine indexing, ranking improvement, traffic improvement, conversion improvement, production readiness, or comparative superiority. The flagship makes no external change.

## Other capabilities

`system.run` is evidence-dependent multi-agent orchestration. `full-site-audit` is broad audit synthesis whose coverage depends on supplied evidence and executed specialist domains. Neither is an alternate flagship command or a completeness guarantee.
