<a id="schema-eligibility"></a>
## Schema eligibility

Schema must describe visible page content, satisfy feature-specific requirements, and avoid marking up claims, reviews, products, jobs, events, or organizations that are not actually present.

<a id="rich-result-validation"></a>
## Rich result validation

Validate syntax, required properties, policy eligibility, rendered-page presence, and Search Console enhancement feedback separately. Rich-result appearance is not guaranteed.
