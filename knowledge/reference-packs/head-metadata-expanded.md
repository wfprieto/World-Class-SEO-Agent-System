<a id="minimum-head-evidence"></a>
## Minimum head evidence

Technical audits should inspect the final head evidence, not only source templates. Record title,
description, canonical, viewport, charset, robots directives, Open Graph metadata, Twitter metadata,
and deprecated tags separately.

<a id="snippet-and-title-quality"></a>
## Snippet and title quality

Title and description work is advisory until it is tied to page purpose and visible content. Search
engines may rewrite snippets, but missing, duplicate, generic, or misleading metadata still indicates
template quality risk.

<a id="head-social-preview"></a>
## Social preview metadata

Open Graph and Twitter metadata do not create rankings by themselves. They are useful when pages are
shared, cited, embedded, or reused by tools that need a clean preview.

<a id="head-deprecated-noise"></a>
## Deprecated head noise

Deprecated or low-value metadata should not be maintained as SEO work unless another documented system
requires it. Keep deterministic rules focused on observable risk and remove legacy noise.
