<a id="technical-triage-sequence"></a>
## Technical triage sequence

Verify URL discovery, crawl permission, HTTP status, canonical selection, renderability, indexability, structured data eligibility, and performance as separate checkpoints. Do not collapse them into one "SEO health" label.

<a id="technical-fix-priority"></a>
## Technical fix priority

Prioritize defects that block crawling, indexing, canonical consolidation, rendering, or conversion-critical performance before cosmetic warnings. Severity requires affected URL count, template scope, business value, and confidence.
